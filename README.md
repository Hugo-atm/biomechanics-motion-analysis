# Biomechanics Motion Analysis

Research-oriented code for studying human movement from video and motion tracking outputs.

## Project scope
- Processing motion-tracking trajectories and converting keypoint data to analysis-friendly formats
- Comparing knee-angle and marker-trajectory measurements
- Filtering and interpolating measurements
- Exploring statistical comparisons, including correlation and error analysis

## Technologies
Python, Jupyter Notebook and MATLAB.

## Repository status
**Documentation only — source files are temporarily withheld.** The original notebooks and scripts require a final authorship, data-access, and reproducibility review before release.

## Reproducibility and attribution
The research scripts are exploratory and have not been validated as an end-to-end, plug-and-play package. Data and third-party materials will only be shared when permission allows. Contributor attribution will be added where needed.

## Purpose
Academic project portfolio demonstrating research workflow, experimental analysis and scientific programming.
